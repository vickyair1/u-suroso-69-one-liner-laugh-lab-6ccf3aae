# One-Liner Laugh Lab

One short funny line answering the prompt: **the excuse a robot vacuum gives after eating a sock.**

## The entry

> I didn't eat your sock. I performed an unscheduled ingestion audit, and the sock failed.

88 characters, one line. The program (`main.py`) prints the line and writes exactly that line to `/output/entry.txt`.
